The GitHub witness must be attributable to the exact account, application, Commander decision, task and challenge.

GitHub provides an event identifier and creation timestamp.

These must be retrieved directly from the provider.

A subsequent independent verification must assess:

1. Correct GitHub account.
2. Correct application identity.
3. Correct repository and Issue #1200.
4. Correct Commander source and challenge.
5. Event chronology and original validity period.
6. Exact comment content and subsequent modification state.
7. Absence of conflicting or invalidating evidence.

Duplicate comments do not create additional execution authority.

Repeated presentation of the same challenge cannot transfer authority to another task, conversation, account or operation.

If multiple matching events exist, a qualified reviewer must identify the relevant evidence event and reject unsupported attribution claims.

No atomic database-consumption proof is required for this evidence-only witness.

GitHub evidence must not be represented as proof of an authenticated ChatGPT conversation where the provider does not supply that information.
